01 · Agent Factory · Docomo Group, at Aays / Aidetic

An agent that answers “at what spend should we stop investing in this media?”

That question needs a diminishing-returns model, not a database lookup. Agent Factory runs the model live and answers in plain Japanese. Its 400 production users, across media, retail, CRM, and order management, ask it questions like that one, or “which products have customer sentiment at risk?”, over 166+ tables and 1,100+ columns of company data.

What makes it different: the business controls which analyses exist. An analyst adds a new analysis, a forecast, a cohort comparison, a clustering model, by filling a form in the UI. The system bends to how the business operates instead of locking it into an off-the-shelf product.

  • I wrote the orchestration, error handling, and processing primitives from first principles, without an agent framework, and kept them simple enough for an analyst to maintain the system unaided.
  • A Python engine runs the statistical models on live data at query time, inside a runtime that keeps conversation, execution, semantics, and data objects in separate states.
  • Every answer is reproducible and auditable: deterministic lineage, access control on every tool, and evaluation hooks.

stackPython, FastAPI, Databricks, LLMs, embeddings.
