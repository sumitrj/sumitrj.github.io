AI CoE

Call Analyzer

Scores every outbound sales call against its SOP, instead of QA sampling a handful.

  • Whisper transcribes each call; prompt-based rule engines grade it step by step against the SOP.
  • Served on vLLM with batching and prompt-redundancy reduction: the shared SOP context is cached once, not recomputed per call.
  • A 4-bit 8B model on one A100 went from ~6,500 to ~29,000 effective input tokens a second on real ~10k-token prompts.

stackPython, Whisper, vLLM, Databricks.

AI CoE

Cricket Ball Tracking

Ball speed and bounce point from ordinary phone video, with no radar or multi-camera rig. There is a worked example below.

  • Motion heuristics cut each frame down to candidate crops; a custom lightweight CNN classifies each one as ball or no-ball, even when the ball is a three-pixel blur.
  • Detections are treated as a noisy time series: velocity limits drop physics-defying outliers, and smoothing gives one clean path per delivery across variable 30 to 60 FPS footage.
  • Tested on 20 hours of footage, which mapped exactly where it held and where it broke: red shoes, crowded frames, low frame rates.

stackPython, PyTorch, OpenCV, NumPy, SciPy.

Open source

CodePulse

Shows coding agents which files matter. There is an interactive page and the code on GitHub.

  • A live call graph built with tree-sitter, refreshed on save, across Python, TypeScript, Dockerfiles, Terraform and YAML. It links environment variables read in Python to where Terraform declares them.
  • One YAML recipe per language, so adding a language is configuration, not code.
  • Served to agents over MCP and to developers in a VS Code panel.
  • On 500 SWE-bench issues, the map plus BM25 ranked the fixed file first 13% more often than BM25 alone (recall@1 0.36 to 0.41).

stackPython, tree-sitter, SQLite, MCP SDK.
